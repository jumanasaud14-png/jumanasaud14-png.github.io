Arabian Leopard Friends — extracurricular prototype

Selected bilingual activities: five storybooks, recorded narration for the two youngest-reader books, four colouring books and tools, welcome videos, and Into the Wild.

This is an early extracurricular concept, outside the curriculum, not an official release or approved plan.

Colouring is stored only in memory within the current browser tab. It is not uploaded or shared and resets when the page reloads. Download artwork to keep it.
